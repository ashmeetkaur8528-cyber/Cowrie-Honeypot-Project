# Cowrie SSH Honeypot Project

## About the Project
This project uses Cowrie, an SSH honeypot designed to detect and monitor suspicious login attempts and attacker activities.

## Technologies Used
- Kali Linux
- Cowrie Honeypot
- Python
- Flask
- SSH
- JSON Logs

## Working
1. An attacker connects to the Cowrie SSH honeypot.
2. Cowrie records login attempts and executed commands.
3. Activity is stored in JSON log files.
4. Python processes the collected information.
5. Flask displays the information on a monitoring dashboard.

## Project Features
- SSH login monitoring
- Attack activity logging
- Command monitoring
- Python Flask dashboard
- Real-time activity monitoring

## Future Scope
- Advanced attack analysis
- IP address tracking
- Improved dashboard visualization
- Automated security alerts
